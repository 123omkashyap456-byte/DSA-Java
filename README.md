## 🚀 How to Run

Make sure Java JDK is installed.

Clone this repository:

```bash
git clone https://github.com/123omkashyap456-byte/DSA-Java.git
```

Navigate to the project:

```bash
cd DSA-Java
```

Compile the Java solution:

```bash
javac LongestSubstring.java
```

Run the program:

```bash
java LongestSubstring
```
